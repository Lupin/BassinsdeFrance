# Bassins de France — Au fil de l’eau

[Ouvrir la carte interactive](https://lupin.github.io/BassinsdeFrance/)

Carte animée des cours d’eau et des sept grands bassins hydrographiques de France métropolitaine. Le site est une page autonome : les données cartographiques nécessaires sont incluses dans `index.html`.

Le dossier `outputs/au-fil-de-leau/` contient aussi les sources séparées de l’application. Les scripts de préparation des données se trouvent dans `work/`. Les données brutes et caches d’extraction ne sont pas versionnés ; ils restent dans le dossier local `work/data/`.

## Ouvrir localement

Ouvrir `index.html` dans un navigateur récent. Certains fonds de carte optionnels nécessitent une connexion Internet.

## Publication

Le site est publié avec GitHub Pages depuis la racine de la branche `main`.
